# TheWebLab

Mi marca personal: vendo sitios web, tiendas online, catálogos digitales y soluciones de digitalización para comercios.

## Estructura

```
TheWebLab/
├── index.html      # Página única de presentación
├── css/
│   └── styles.css  # Estilos (tema oscuro, responsive)
├── js/
│   └── main.js     # Menú móvil, animaciones, formulario
└── README.md
```

## Detalles

- Animaciones: elementos que aparecen al hacer scroll, brillo que sigue al cursor, barra de progreso, palabras rotativas en el hero, orbes flotantes, botones magnéticos y botón de volver arriba. Todo respeta `prefers-reduced-motion`.

## Ver el sitio localmente

Abrí `index.html` en el navegador, o servilo con:

```bash
python -m http.server 8000
```

Y visitá `http://localhost:8000`.
